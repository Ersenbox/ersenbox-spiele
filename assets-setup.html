🎯 3 Deployment Options

✅ OPTION 1: Cloudflare Pages (EMPFOHLEN)

Best für dein Ersenbox Setup! Schnell, kostenlos, mit Workers Integration.

1. GitHub Repo erstellen: github.com → New Repository → ersenbox-spiele 2. Lokale Folder hochladen: $ git clone https://github.com/username/ersenbox-spiele $ cd ersenbox-spiele $ cp index.html . $ cp -r assets/ . $ git add . $ git commit -m "Initial Ersenbox Setup" $ git push origin main 3. Cloudflare verbinden: Dashboard → Pages → New Project → Select Repo Build: None (Static files) Deploy Directory: / 4. URL: ersenbox-spiele.pages.dev

✓ Vorteil: Automatisch deployt bei jedem git push

⚡ OPTION 2: Vercel (Schnell)

Noch schneller als Cloudflare, kostenlos für Hobby-Projekte.

vercel.com → Import Project → Select GitHub Repo (Es wird automatisch erkannt und deployed) URL: ersenbox-spiele.vercel.app

🌐 OPTION 3: Lokaler Server (Testen)

Zum lokal entwickeln & testen:

# Python 3 $ cd ersenbox-spiele $ python -m http.server 8000 # Oder Node.js $ npx http-server -p 8000 Öffne: http://localhost:8000

🔧 Troubleshooting

❌ "Images not loading"

Lösung: Check relative paths

Browser F12 → Network → Check image URLs Sollte sein: /assets/images/characters/lion.png Nicht: https://external-url/...

❌ "404 Not Found"

Lösung: Overprüfe Ordnerstruktur

$ ls -la assets/images/characters/ (Sollte alle 8 Character-Bilder zeigen)

❌ "Slow loading"

Lösung: Bilder sind groß (1-2MB each). Optimieren:

# Mit ImageMagick $ convert input.png -resize 1200x1200 -quality 85 output.png # Online: Tinypng.com
